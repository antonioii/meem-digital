# MEEM — Mini-Exame do Estado Mental

Aplicativo simples para auxiliar na aplicação e na pontuação do Mini-Exame do Estado Mental (MEEM). Funciona diretamente no navegador, em computadores e celulares.

## Como usar

1. Abra o arquivo `escala-meem-svg.html` em um navegador atualizado, ou acesse diretamente o deploy do GitHub em https://antonioii.github.io/meem-digital/. Não é necessária instalação ou conexão com a internet.
2. Use o cronômetro no início da página para acompanhar o tempo da aplicação. É possível iniciar, pausar e zerar a contagem.
3. Selecione a via de atenção e a escolaridade e marque as respostas corretas em cada seção.
4. A pontuação e a interpretação são atualizadas automaticamente. Use **Limpar respostas** para iniciar uma nova avaliação; o cronômetro possui controle de zerar independente.

A pontuação total é de até 30 pontos. O aplicativo apresenta os pontos de corte por escolaridade e um modelo visual para a tarefa de cópia.

## Observação

O MEEM é um instrumento de rastreamento. Seus resultados devem ser interpretados no contexto clínico, cultural e educacional, por profissional habilitado.
